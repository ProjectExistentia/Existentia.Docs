# Decisões de arquitetura (ADR)

Os **ADRs** registram as decisões de arquitetura mais importantes do projeto,
com contexto, decisão e consequências. São a fonte de verdade para *por que* o
sistema está sendo construído de determinada forma.

|--|---------|--------|
| [ADR-0001](ADR-0001-arquitetura-e-stack) | Stack e Arquitetura de Alto Nível | Aceito |
| [ADR-0002](ADR-0002-estrutura-de-repositorios) | Estrutura de Repositórios | Aceito |
| [ADR-0003](ADR-0003-workflow-de-desenvolvimento) | Workflow de Desenvolvimento | Aceito |

---

> **Padrão de navegação (Variante A):** cada ADR individual usa `unlisted: true`
> e não aparece na sidebar — é acessado apenas pela lista acima. Se a navegação
> ficar pesada com o crescimento, migra-se para a **Variante B** (sem submenus,
> lista única agrupando todos os tipos).
>
> Novos ADRs devem seguir o formato MADR usado em
> [ADR-0001](ADR-0001-arquitetura-e-stack) e o template em
> [Gestão → Templates](/docs/gestao/templates/template-adr).
