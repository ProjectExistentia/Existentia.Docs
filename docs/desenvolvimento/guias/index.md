# Guias de desenvolvimento

Estrutura mínima reservada para os guias práticos de desenvolvimento do
monorepo. Cada guia será criado conforme a necessidade, seguindo o padrão de
documentação do projeto.

## Guias planejados

| Guia | Conteúdo previsto |
|------|-------------------|
| Setup | Clonar, instalar dependências, ferramentas (SDK, IDE) e executar a solução |
| Código | Padrões de projeto, organização de namespaces/projetos, convenções de escrita |
| Contribuição | Fluxo trunk-based, PRs, Conventional Commits, revisão |
| Infraestrutura | Build, CI/CD, deploy, configuração de ambientes |
| Arquitetura | Detalhamento da arquitetura além dos ADRs |

> Os ADRs em [Decisões de arquitetura (ADR)](/docs/desenvolvimento/ADR) são a
> fonte de referência de decisões; estes guias trazem o "como fazer" no dia a dia.
