# ADRs — Architecture Decision Records

Os **ADRs** registram as decisões de arquitetura mais importantes do projeto, com
contexto, decisão e consequências. São a fonte de verdade para *por que* o sistema
está sendo construído de determinada forma.

## Decisões registradas

- [ADR 0001 — Stack e Arquitetura de Alto Nível](arquitetura-e-stack)
- [ADR 0002 — Estrutura de Repositórios](estrutura-de-repositorios)
- [ADR 0003 — Workflow de Desenvolvimento](workflow-de-desenvolvimento)

> [ADR 0001](arquitetura-e-stack).
