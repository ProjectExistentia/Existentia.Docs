# Requisitos Funcionais (RF)

Esta seção reúne os **requisitos funcionais** do sistema. Cada RF descreve uma
capacidade que o sistema deve prover, com identificador, descrição, prioridade e
vínculos com casos de uso e regras de negócio.

> Em construção — os requisitos serão extraídos do domínio definido no
> `Existentia.Lore` (fonte canônica) e detalhados aqui nesta seção.
