# RN-001 — Criação por conceito

## Regra

A criação de personagem é dirigida por **conceito narrativo**, não por seleção
mecânica de habilidades. O jogador define *quem* quer ser e o sistema revela as
opções mecânicas a partir disso. O jogador não precisa conhecer as regras para
criar um personagem.

Processo (passo a passo):

1. Definir o **conceito** (quem é o personagem).
2. Escolher a **raça** (Humano, Anão, Elfo, Bárbaro, Homem-Fera, Titã).
3. Definir **origem e história**.
4. Receber os **traços** atribuídos pelo Mestre com base na história.
5. O Mestre define o **custo** do personagem em Pontos de Talento.
6. Escolher **talentos** dentro do custo, limitados pelos traços.
7. Finalizar a **ficha** (perícias, equipamentos, detalhes).
